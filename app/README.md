# orders_heroku
orders multi services
rep for heroku

## Модули

- [Отчёт первичного заказа](utilities/admin/first_order_report.md) — пользователи по дате первого отправленного заказа, их контакты и агенты.


При копировании обычного GTIN-заказа проверяются проводящая компания заказа и компании GTIN в позициях и размерах по актуальному `CompaniesOperators`. Если компания исключена из списка или не указана для GTIN, копирование блокируется до создания нового заказа с сообщением о недоступности компании и связанных GTIN для проверки в «Честном ЗНАКЕ». Обычные заказы без GTIN не затрагиваются; у заказов карточек товаров сохраняется отдельная проверка.
