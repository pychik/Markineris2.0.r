# Детские чулочно-носочные изделия

Основной сервис и Markineris2.0.r, ветка `socks_children`. Размерные сетки
обновлены по таблице «носки игорь детские и взрослые.xlsx».

## Схема БД перед запуском

В таблицу `socks` каждого сервиса требуется добавить `is_children BOOLEAN NOT NULL DEFAULT false`.
Локальные миграции подготовлены в `app/migrations/versions/` каждого проекта и исключены из Git.
Они добавляют колонку и устанавливают `true` для существующих строк с полом «Детск.».
Применение миграций выполняет владелец проекта; автоматически они не запускаются.
Код нельзя запускать с прежней схемой: ORM ожидает новую колонку.

Для существующих строк с `gender = 'Детск.'` рекомендуется при переносе данных установить
`is_children = true`. Для «Без указания пола» и других значений нельзя надёжно определить
детский товар только по полу: такие старые позиции требуют отдельной проверки.

## Форма и хранение

«Детский товар» хранится у позиции, отдельно от пола. При включении переключателя
автоматически выбирается «Без указания пола». При выборе старого значения «Детск.»
переключатель тоже включается, а пол заменяется на «Без указания пола».
Детские и взрослые позиции могут находиться
в одном заказе с одинаковым товарным знаком, артикулом и цветом; автоматически
объединяться они не должны. Режим учитывается при проверке дублей и объединении карточек.

При смене режима очищаются только размеры и количества текущей формы. Сохранённые
позиции заказа остаются на месте. В карточке на уточнении режим менять нельзя,
поскольку размеры такой карточки зафиксированы.

Детские размеры:

| Тип в форме / хранении | Значения |
| --- | --- |
| РОССИЯ | 6, 8, …, 28; 6-8, 8-10, …, 26-28 |
| МЕЖДУНАРОДНЫЙ | 6, 8, …, 28; 6-8, 8-10, …, 26-28 |
| month | 0-3, 3-6, 6-9 |
| years | 1, 2, …, 14; 1-2, 2-3, 3-4, 1-3 |
| ОСОБЫЕ_РАЗМЕРЫ | ONE SIZE (хранится как МЕЖДУНАРОДНЫЙ) |

В интерфейсе возрастные группы подписаны «ВОЗРАСТ — МЕСЯЦЫ» и «ВОЗРАСТ — ГОДЫ».
Возраст и числовые размеры независимы: таблицы соответствия нет.
При сохранении и импорте по-прежнему принимаются прежние значения лет `1,5`,
`4-5`, `6-7`, `8-9`, `10-12` и российский размер `7` для совместимости со старыми позициями.
В новую сетку выбора они не входят. `1.5` нормализуется в `1,5`.

Во взрослом режиме существующие сетки сохраняются. Для всех вариантов пола добавлен
тип «ДЛИНА СТОПЫ»: 6-8, 7-9, …, 31-33 (разница границ 2, начало с шагом 1).
Значение не содержит `см`. Детскому товару этот тип недоступен.

## Excel и выгрузка

В шаблон `носки_по каждому размеру.xlsx` добавлена колонка S «Детский товар»
с вариантами «Да» и «Нет». Колонка I сохраняет явно указанный тип размера,
включая `month`, `years`, числовой `МЕЖДУНАРОДНЫЙ` и `ДЛИНА СТОПЫ`.
Возрастные значения нужно вводить текстом, чтобы Excel не превращал диапазоны в даты.

Если колонки «Детский товар» нет или значение пустое, импорт определяет детский
товар по полу «Детск.», типу `month`/`years` или числовой детской сетке с типом
РОССИЯ/МЕЖДУНАРОДНЫЙ. Пол такой позиции заменяется на «Без указания пола».
ONE SIZE неоднозначен: для него детский режим задаётся явно через «Да».
«ДЛИНА СТОПЫ» без явного флага относится ко взрослым независимо от значения.
Явное «Нет» не переопределяется: детский размер с этим флагом отклоняется.

Импорт принимает `2-3 years` с типом years, МЕЖДУНАРОДНЫЙ или пустым типом,
сохраняя внутренний тип years и значение `2-3`. Значения `0-3`, `3-6`, `6-9`
с международным или пустым типом распознаются как month. В остальных случаях
пустой тип определяется прежним способом: латиница — международный, числа — российский.
Некорректные сочетания режима, типа и размера отклоняются при импорте,
сохранении формы/карточки и проверке совместимости сохранённой позиции.

В Excel-шаблоне обновлены список типов, подсказки и независимые справочники
детских и взрослых размеров. Таблица соответствия возраста числовым размерам удалена.
Значения размеров хранятся текстом, чтобы диапазоны не превращались в даты.
Формула наименования заполнена в B7:B1045. Она определяет детский товар
по тем же типам и размерам, учитывает явный флаг «Да»/«Нет» и добавляет «детские».
Для ONE SIZE режим определяется флагом (или старым полом «Детск.»),
а не самим размером; «ДЛИНА СТОПЫ» не включает детский режим автоматически.
Для лет в наименование добавляется years, для месяцев — только числовой диапазон.
Формула является предварительным отображением: при загрузке столбец B не используется,
а окончательное наименование по-прежнему формируется сервером из полей товара.
Расчёт формул включён автоматически при открытии книги в Excel/LibreOffice.

В обычной выгрузке у детских позиций указывается тот же регламент, что у детской
одежды: ТР ТС 007/2011; у взрослых — ТР ТС 017/2011. Регламент в этой правке не меняется.
Выгрузка 029 использует для возраста тип МЕЖДУНАРОДНЫЙ: годы идут как `2-3 years`,
месяцы как `0-3`, без подписи месяцев. Длина стопы выгружается с собственным типом
и исходным диапазоном. В наименование детского товара добавляется «детские»
по признаку is_children, независимо от значения пола. Например:
`НОСКИ детские БРЕНД арт. A1 цвет БЕЛЫЙ р. 2-3 years`.
ТН ВЭД выбирается существующим механизмом, эта задача его не меняет.

В формате 046 значения возрастных размеров сохраняются без пересчёта в числовой
размер. Используется существующий код типа «МЕЖДУНАРОДНЫЙ»;
новые коды справочника 046 не вводятся. Отдельной колонки регламента в текущей
выгрузке 046 нет.
